# moorpheus

A boat anchor-alarm prototype using the Raspberry Pi Pico 2 W, with a
[hardware build guide](docs/pico_2_w_anchor_alarm_build_guide_v2.md) and
[display layout concepts](layouts/index.html).

This is a prototype, not a certified marine safety system. See the build guide
for limitations and safety considerations.
